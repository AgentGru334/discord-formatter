How to use TackleBox

Everything you need to compose, share, and keep a backup.

Write your first message
  1. Choose Message and type in the Visual editor, or start with a template.
  2. Select words and tap Bold, Underline, Spoiler, or another formatting button.
  3. Check the preview and character count. Copy for Discord copies the actual Discord syntax.
  4. Paste into Discord and review before sending. This app never posts on your behalf.

Markdown view lets you edit the exact output. Switching back to Visual normalizes supported formatting; use Markdown view for unusual Discord syntax you want to preserve exactly.

Each mode has its own saved draft. New draft clears only the current mode after confirmation. Export a backup before clearing browser data.

ANSI colors & programming snippets

ANSI colors: select text and choose a text color or fill. Bold and underline can be combined with colors. Copy includes an ansi code block and actual escape characters, with resets to stop color bleeding.

ANSI and syntax colors may differ or be unavailable in Discord clients, especially on mobile. For messages your whole team must read consistently, use ordinary Message formatting. The preview is an approximation.

Code snippet: choose a language and paste your code. The app adds the opening and closing triple backticks and language label. Example buttons load illustrative snippets; this app does not execute code.

If your snippet contains triple backticks, remove or separate them before copying: they can close the Discord block early. The output viewer shows ANSI escape characters as “␛” for inspection; the Copy button uses real escape characters.

Templates, placeholders & validation

Preview a template, fill its named fields, then load it into the composer. Gaming examples are blank layouts, not verified game data or redeemable codes.

Save any draft as a template. Use {Field name} for reusable fields. A saved template keeps its mode and formatting. Custom templates can be renamed or deleted.

Validation counts the final output, including code fences and color sequences. Choose a 2,000 or 4,000 character account limit and optionally add stricter rules. A required field such as Reward needs a line like Reward: 3 keys. Rules warn by default; enable blocking if your team needs it.

Install, use offline & share with your team

For installation, open the hosted HTTPS app in your phone’s browser. On Android/Chrome, use Install app or the browser’s “Install app” menu. On iPhone/Safari, use Share → Add to Home Screen.

Open the hosted app once while online to cache its files. Once caching succeeds, the core editor, templates, and backups work offline. Remote config updates still need a connection.

A downloaded standalone HTML file is a portable backup. It cannot install a service worker from a file address; its drafts depend on the browser’s local-file storage support.

Share the hosted address with coworkers. Templates do not synchronize between devices automatically unless each device is configured to load your shared JSON URL. Export/import also works without a hosting account.

Clipboard, storage & troubleshooting

If clipboard access is blocked, the app opens the output for manual selection and copying. On a phone, long-press the selected text and choose Copy.

If saving is unavailable or storage is full, an alert appears. Export your backup before closing. Private browsing and clearing browser data can remove saved drafts and templates.

The preview cannot guarantee Discord’s exact fonts, colors, emoji, or link behavior. Mentions and channel references are not resolved here. Backticks don’t guarantee tap-to-copy behavior in every Discord client.

Everything is processed in your browser. Only a team config URL you explicitly enable makes remote requests. Imported configuration is treated as data, never executable code.
